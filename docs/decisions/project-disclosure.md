# Project disclosure controls

Chosen from the project-disclosure prototype: Fine lines.

- Thin 12px plus when closed; a horizontal minus when open.
- Keep the compact 36px project row height from Arrow + underline.
- Show the control on hover, keyboard focus, and while expanded.
- Start every project closed.
- Keep underlined external links with their external-link arrow.
- Rename the organization link to Liferay SEO & AEO Studio.

Rejected directions: the chevron felt inelegant; the original arrow was too similar to the external-link arrow. The View / Close text direction was explored but not selected. Arrow + underline supplied the preferred spacing, while Fine lines supplied the chosen icon treatment.
